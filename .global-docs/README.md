# Global Docs

This directory holds documentation and templates that are **shared across all repos** in `src/`.

To onboard a new project:

1. Copy `TEMPLATE_AGENT.md` into your repo root and rename it for your agent
   (`CLAUDE.md`, `GEMINI.md`, `.cursorrules`, etc.).
2. Fill in every section — mark anything that does not apply as `N/A`.
3. Copy `TEMPLATE_PLAN.md` into your repo's `.docs/` directory when you start a feature.

| File | Purpose |
|------|---------|
| `TEMPLATE_AGENT.md` | Starting point for a repo-level agent file. |
| `TEMPLATE_PLAN.md`  | Per-feature planning template. |
